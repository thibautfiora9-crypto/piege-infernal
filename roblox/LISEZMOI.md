# Ville Folle sur Roblox : comment le publier depuis ton Mac

## 1. Installer Roblox Studio
1. Sur ton Mac, va sur **create.roblox.com** et connecte-toi avec ton compte Roblox.
2. Clique sur **Créer** puis télécharge **Roblox Studio** (gratuit) et installe-le.

## 2. Télécharger le jeu
Sur ton Mac, ouvre ce lien : le fichier se télécharge.
https://thibautfiora9-crypto.github.io/piege-infernal/roblox/VilleFolle.rbxlx

## 3. Ouvrir le jeu
1. Lance Roblox Studio.
2. Menu **Fichier → Ouvrir depuis un fichier** (File → Open from File), puis choisis `VilleFolle.rbxlx` (dans Téléchargements).
3. Clique sur le gros bouton **▶ Jouer** (Play) en haut pour tester : la ville se construit toute seule en quelques secondes.

## 4. Publier sur Roblox
1. Menu **Fichier → Publier sur Roblox** (File → Publish to Roblox).
2. Donne un nom (par exemple « Ville Folle ») et une description, puis **Créer**.
3. Va dans **Accueil → Paramètres du jeu** (Game Settings) :
   - **Sécurité** : active **« Activer l'accès aux API Studio »** (Enable Studio Access to API Services). C'est ce qui permet de **sauvegarder l'argent** des joueurs.
   - **Autorisations** : mets le jeu en **Public** quand tu veux que tout le monde puisse jouer.
4. Roblox te demandera de remplir le **questionnaire de maturité** (il y a des armes) : réponds honnêtement.

## Ce qu'il y a dans cette première version
- Une ville générée automatiquement : routes, trottoirs, immeubles, lampadaires, jour/nuit
- Des voitures garées partout : assieds-toi dans le siège conducteur pour conduire (ZQSD / WASD ou les flèches)
- Un pistolet au départ, et une **Armurerie** (fusil d'assaut, fusil à pompe, sniper avec zoom au clic droit)
- Des **supérettes** et des **banques** à braquer (arme en main, maintenir **E**)
- Des **étoiles** : la police arrive, te poursuit et te tire dessus. Reste caché 20 secondes pour la semer.
- **Auto Folle** : achète une sportive ou une supercar
- **Casino Fortuna** : machine à sous
- L'argent et les armes achetées sont **sauvegardés**
- Le **multijoueur** est automatique : tes potes rejoignent ton serveur

## Si quelque chose ne marche pas
Dans Roblox Studio, ouvre **Affichage → Sortie** (View → Output) : les erreurs s'y affichent en rouge.
Fais une capture d'écran et envoie-la-moi, je corrige.
